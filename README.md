# ISSSSMAIL Scalper Bot — الدليل الكامل

## 📁 هيكل المشروع

```
issssmail/
├── main.py              ← نقطة التشغيل الرئيسية
├── START_BOT.bat        ← ملف التشغيل بضغطة واحدة (Windows)
├── state.json           ← يُنشأ تلقائياً - يحفظ سجل الصفقات
├── issssmail_bot.log    ← ملف اللوج
│
└── bot/
    ├── config.py        ← جميع الإعدادات (TP, SL, هدف يومي...)
    ├── analysis.py      ← محرك التحليل الفني (EMA + RSI)
    ├── mt5bridge.py     ← الاتصال بـ MetaTrader 5
    ├── engine.py        ← المحرك الأساسي للبوت
    └── server.py        ← خادم HTTP API (port 8765)
```

---

## 🚀 طريقة التشغيل

### الطريقة السريعة:
1. افتح MT5 وتأكد من تسجيل الدخول
2. فعّل **Algo Trading** في MT5 (زرار في شريط الأدوات)
3. اضغط مرتين على `START_BOT.bat`
4. افتح **داشبورد.html** في Antigravity

### الطريقة اليدوية:
```bash
cd "C:\Users\hassa\Desktop\all project\issssmail"
python main.py
```

## 📊 استراتيجية التداول

### الرموز: XAUUSD (ذهب) + BTCUSD (بيتكوين)

### منطق الاستراتيجية:
1. **تحليل الاتجاه** عبر EMA9 و EMA21 على إطار M5
2. **فلتر RSI** لتجنب الدخول في مناطق التشبع
3. **فتح صفقة** في اتجاه السوق بمكسب صغير
4. **وقف الخسارة**: إغلاق الصفقة عند -$0.50 → فتح صفقة جديدة فورًا
5. **جني الأرباح**: إغلاق تلقائي عند +$0.50

### قواعد إدارة المخاطر:
- لا يفتح البوت أكثر من 2 صفقات في نفس الوقت
- عند تحقق الخسارة اليومية ($20) يتوقف عن الدخول
- يستمر في العمل حتى يضغط المستخدم "إيقاف"

## ❓ استكشاف الأخطاء

**البوت لا يتصل بـ MT5؟**
- تأكد أن MT5 مفتوح ومسجل الدخول
- فعّل "Algo Trading" من شريط الأدوات في MT5

**الداشبورد يقول "غير متصل"؟**
- تأكد أن `main.py` يعمل
- API يعمل على `http://127.0.0.1:8765`

**الصفقات لا تُفتح؟**
- تحقق من `issssmail_bot.log`
- تأكد من وجود رصيد كافٍ في الحساب
