## 📊 نظام التسجيل (7 نقاط)

```
1. EMA9 vs EMA21 (تقاطع الاتجاه)         +1
2. MACD Histogram (زخم الحركة)            +1
3. RSI Zone (بعيد عن الذروة)             +1
4. Bollinger Bands (موضع السعر)           +1
5. ADX > 25 (اتجاه حقيقي مش رينج)        +1
6. M15 HTF EMA (تأكيد الإطار الأعلى)     +1
7. Stochastic %K (تأكيد إضافي)           +1

الحد الأدنى للتداول: 5/7 نقاط
```

## 🛡️ فلاتر الحماية

- **فلتر السبريد**: TP / spread ≥ 1.8 (وإلا: WAIT)
- **فلتر ADX**: ADX < 20 = سوق راكد → لا تداول
- **فلتر جلسات**: الذهب 07:00–20:00 UTC فقط
- **حماية خسائر متتالية**: بعد 3 خسائر متتالية → إيقاف مؤقت
